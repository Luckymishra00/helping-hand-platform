# Helping Hand 🤝

A community platform that helps village people find jobs and connect with skilled workers based on required services and skills.

## Features
- User Authentication
- Job Posting System
- Worker Search Functionality
- Dashboard Interface
- Responsive Design
- Community Support Platform

## Technologies Used
- Python
- Flask
- SQLite
- HTML5
- CSS3
- JavaScript

## Project Structure
- Templates for frontend pages
- Static files for CSS and JavaScript
- Flask backend for routing and authentication
- SQLite database integration

## Purpose
This project was developed to support rural communities by making local job opportunities and worker hiring easier and more accessible.
